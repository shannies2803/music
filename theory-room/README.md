# The Theory Room

A self-paced music website for ABRSM and Trinity exams, Grades 1–8: theory drills and guided courses, aural tests, sight-reading, an exam repertoire guide and composer films, with family logins, payments and teacher classes.

- **Getting it live:** read [SETUP.md](SETUP.md). You only edit `config.js`, plus settings on Supabase, Lemon Squeezy and Netlify.
- **Trying it now:** open `index.html` in a browser. Without the keys in `config.js` it runs in preview mode, with a switch to see it as a free family, a Family plan family, a Grade 5 pack or a teacher.
- **Keep this repository private.** The paid course files are in it.

The Theory Room is independent and is not affiliated with ABRSM or Trinity College London.
